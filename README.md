# PBPMP_2017

This repository is an alias for **[pachterlab/sleuth_paper_analysis](https://github.com/pachterlab/sleuth_paper_analysis)**, which contains the code and analysis for:

Harold Pimentel, Nicolas L. Bray, Suzette Puente, Páll Melsted, and Lior Pachter. **[Differential analysis of RNA-seq incorporating quantification uncertainty](https://doi.org/10.1038/nmeth.4324)**. *Nature Methods* 14, 687–690 (2017).

**[Go to the code and documentation →](https://github.com/pachterlab/sleuth_paper_analysis)**

The alias follows the Pachter Lab convention of author last-name initials in order followed by the publication year. The original sleuth_paper_analysis repository remains the source of the code and retains its existing URL.
